# Fiverr-Gigs (Anlage ca. 30 Min.)

**Wichtige Fiverr-Regeln:**
- Kommunikation und Zahlung laufen **ausschließlich über Fiverr**. Fiverr-Käufer also nie auf unsere Stripe-Links oder unsere E-Mail verweisen, sonst droht eine Sperre.
- Fiverr nimmt 20 %. Das ist bei den Preisen schon einkalkuliert.
- Falls Fiverr beim Anlegen nach KI-Nutzung fragt: wahrheitsgemäß „AI-assisted“ angeben.

**Kategorie:** Programming & Tech → (AI) Agents / Workflow Automation. Nimm die passendste Unterkategorie mit „n8n“ oder „Automation“.

**Anforderungen an den Käufer:**
1. Describe what should happen (trigger → steps → result).
2. Which apps/services are involved?
3. n8n Cloud or self-hosted? Which version?
4. Sample data or screenshots (no passwords, please).

**FAQ:**
- *Do you need access to my n8n?* No. You get an import file and add your credentials yourself. We can do it together on a call.
- *Self-hosted or cloud?* Both work.
- *What if it breaks later?* Fixes for the agreed scope are included for the support period.
